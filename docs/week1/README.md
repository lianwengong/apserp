## 已知坑（来自设计阶段）

1. `sys` 是 SQL Server 保留架构 → 平台层用 `plat`
2. `Rule` 是保留字 → 表名用 `BizRule`
3. 连接池复用会让 `SESSION_CONTEXT` 串租户 → 统一走 `TenantSession`
4. Flyway 对 `GO` 的支持因版本而异 → 备选 `tools/strip_go.py`
5. 明细表原本没有 `TenantId` → 已补，RLS 才能覆盖
